MarkinJS Interactive Example

Click an annotation to select it, then drag it, its corners, its vertices or its keypoints. Pinch or hold Ctrl / Cmd and scroll to zoom, then drag the empty canvas to move around.

Coordinates are in image pixels (1280 × 853), whatever size the image is shown at.

Create an editor and save on change

const editor = MarkinJS.create('demo-image', {
    annotations: [
        { id: 'boat', class_id: 0, bbox: [557, 545, 302, 96] }
    ],
    colors: { 0: '#2563eb', 1: '#16a34a' }
});

// One event after every completed edit,
// carrying the full list in the same format.
editor.on('change', (annotations) => {
    save(annotations);
});

One format, in and out

{
    "id": "chair",
    "class_id": 1,
    "bbox": [x, y, width, height],
    "segments": [[x, y], [x, y], [x, y]],
    "keypoints": [
        { "name": "seat", "point": [x, y], "v": 2 }
    ]
}

bbox, segments and keypoints are optional; at least one is needed. Fields MarkinJS does not know are kept as they are.

Change things from code

const id = editor.createAnnotation({ bbox: [100, 100, 200, 150] });
editor.updateAnnotation(id, { class_id: 2 });
editor.select(id);
editor.deleteAnnotation(id);

editor.load(annotationsFromServer); // replace everything
editor.undo();

Keyboard

  • Arrow keys: move by 1 pixel, Shift by 10, Ctrl / Cmd by 0.2
  • Delete or Backspace: delete the selection
  • Ctrl / Cmd + Z: undo. Ctrl / Cmd + Shift + Z or Ctrl + Y: redo
  • Escape: cancel a drag, or deselect
  • + and -: zoom. Shift + 1: the whole image. Shift + 0: real pixels
  • Space, held: a drag moves the view from anywhere

Keys typed into a text field are never taken by the editor.

Zoom and pan

  • Pinch, or Ctrl / Cmd + wheel: zoom towards the pointer
  • Wheel or two-finger scroll: move the view
  • Drag the empty canvas: move the view, once it is zoomed in
  • Space + drag or the middle button: move it from anywhere

While the whole image is in view, the wheel scrolls the page as usual.

Use what is visible

editor.zoomTo(id);            // frame one annotation
editor.step(1);               // select and frame the next one

// The visible part, in whole image pixels: a crop.
editor.on('viewsettle', (view) => {
    analyse(view.x, view.y, view.width, view.height);
});
